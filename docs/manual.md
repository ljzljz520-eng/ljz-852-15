# 用户手册

## 1. 简介
欢迎使用 Manticore DHT 搜索引擎。本系统提供全网磁力资源的快速检索服务，专注于速度与隐私。

## 2. 如何使用

### 2.1 搜索资源
1. 打开首页。
2. 在搜索框输入关键词（推荐使用**完整单词**）。
   - ✅ 正确示例: `Ubuntu`, `Avengers`, `Python`
   - ❌ 错误示例: `Ubu`, `Pyth` (目前不支持英文单词前缀模糊搜索)
3. 点击“搜索”按钮或按回车键。

### 2.2 过滤与排序搜索结果
搜索结果页左侧提供过滤器，所有条件都会实时反映在浏览器地址栏的 URL 中，可以直接复制链接分享给他人（对方打开后看到完全相同的关键词与筛选条件）：

- **文件类型**：视频 / 音频 / 图片 / 压缩镜像 / 文档 / 软件 / 其他，可多选（多选为“或”关系）。
- **标签**：根据资源名称自动归类的内容标签（电影、剧集、动漫、音乐、游戏、软件资源、电子书），可多选。
- **大小区间**：以 MB 为单位填写最小值和/或最大值，点击“应用大小”。
- **收录时间**：可点“24 小时 / 近 7 天 / 近 30 天 / 近一年”快捷预设，也可用起止日期自定义。
- **排序**：结果区右上角可在**相关度**（默认，有关键词时）、**时间**、**大小**之间切换；没有关键词时相关度不可用，默认按收录时间排序。

切换过滤器或翻页时，当前关键词会始终保留；已生效的条件会显示在结果上方，点击条件旁的 ✕ 可单独移除，侧栏顶部“清除”可一键清空全部过滤条件。

URL 参数示例：
```
/search?q=Ubuntu&types=archive&tags=software&smin=104857600&since=1717200000&sort=new
```

### 2.3 查看详情
在搜索结果列表中，点击资源标题即可进入详情页。详情页包含：
- **基本信息**: 资源名称、大小、收录时间。
- **磁力链接**: 点击“复制磁力链”即可获取下载链接。
- **文件列表**: 预览资源内包含的所有文件。

### 2.4 迅雷下载
在详情页，如果已安装迅雷等支持软件，尝试点击“打开”按钮可能会直接唤起下载工具。如果浏览器拦截，请使用“复制磁力链”功能后在下载软件中新建任务。

## 3. 常见问题
- **Q: 为什么搜不到结果？**
  - A: 请确认输入的关键词是否拼写正确，或关键词是否过于冷门。
- **Q: 为什么提示不支持前缀搜索？**
  - A: 为了保证中文搜索的精准度，当前索引配置限制了部分英文的模糊匹配能力。请尽量输入全称。
