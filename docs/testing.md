# 测试计划

## 1. 测试范围
- **功能测试**: 搜索功能、详情页展示、磁力链复制。
- **兼容性测试**: 响应式布局在桌面端和移动端的表现。
- **性能测试**: 并发搜索时的响应速度。

## 2. 手动测试用例

| ID | 模块 | 测试步骤 | 预期结果 |
| :--- | :--- | :--- | :--- |
| TC01 | 首页 | 访问 `http://localhost:3000` | 页面正常加载，并在搜索框下方看到提示语 |
| TC02 | 搜索 | 输入 "Ubuntu" 并提交 | 列表页显示 Ubuntu 相关 ISO 资源，默认按相关度排序 |
| TC03 | 搜索(部分) | 输入 "Ubu" 并提交 | 列表页提示未找到或显示相近结果，且有不支持前缀搜索的提示 |
| TC04 | 详情 | 点击搜索结果中的条目 | 进入详情页，显示文件列表和文件大写 |
| TC05 | 复制 | 点击“复制磁力链”按钮 | 提示“已复制”，剪贴板中存在 magnet 链接 |
| TC06 | 文件类型过滤 | 搜索后勾选侧栏“视频”，再追加“音频” | URL 依次出现 `types=video`、`types=video,audio`，结果随过滤变化；再次点击已选项可取消 |
| TC07 | 标签过滤 | 点击标签“电影” | URL 出现 `tags=movie`，“已选条件”区出现可单独移除的标签，且 `q` 关键词保持不变 |
| TC08 | 大小区间 | 在大小区间输入 100 ~ 1024 MB 并应用 | 跳转后 URL 含 `smin=104857600&smax=1073741824`，输入框回显 100/1024，结果均在区间内 |
| TC09 | 收录时间 | 点击“近 7 天”预设 | URL 含 `since`/`until` 时间戳，结果收录时间均在最近 7 天 |
| TC10 | 排序 | 依次切换“相关度/时间/大小” | URL 的 `sort` 在 `relevance/new/size` 间切换，结果顺序正确；无关键词时相关度按钮禁用 |
| TC11 | URL 分享 | 复制带全部过滤参数的 URL 在新窗口打开 | 页面还原相同的关键词、过滤器与排序；访问带非法值（如 `types=foo`）会 302 到规范化 URL |
| TC12 | 保持关键词 | 在过滤后的结果页顶部搜索框改词提交 | 新搜索仍携带原有 `types/tags/smin/...` 参数 |
| TC13 | 分页 | 在过滤结果上点下一页 | 分页链接保留全部过滤参数与关键词 |
